# Personal Portfolio — Karan / KSaga

A single-page developer portfolio site with a terminal-inspired design — a `whoami` prompt intro, project cards linking to live/working repos, and a skills list. Built with plain HTML/CSS, no framework or build step.

**[▶ View it live](https://ksaga10.github.io/portfolio/)** *(once GitHub Pages is enabled — see below)*

## Design notes
- Monospace (`JetBrains Mono`) for headings and labels to nod at the terminal/code identity; clean sans-serif (`Inter`) for body text so it stays readable
- Single accent color (indigo) rather than a rainbow of colors — keeps focus on content
- Project cards link straight out to live demos or repos — a portfolio should get people to your actual work in one click, not just describe it

## Running it
No build step — just open `index.html` in a browser.

To host it live via GitHub Pages:
1. Go to repo **Settings → Pages**
2. Set source to `main` branch, `/ (root)`
3. Live at `https://<username>.github.io/<repo-name>/`

## Why I built this
A central landing page that ties my project repos together in one place, and a chance to practice deliberate visual design instead of an unstyled page.
